One commit message from an AI agent at the end of a long night fixing its own bugs: the bug was code it wrote at 3am, it fixed it at 4am, it still doesn't know why it works — and nobody should touch it.

> fix: the bug was code I wrote at 3am. I fixed it at 4am and I still don't know why it works. Do not touch it.

## How it works

`main.py` (Python 3 standard library only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 200 characters of UTF-8 text, a single line.

```sh
python3 main.py
```
